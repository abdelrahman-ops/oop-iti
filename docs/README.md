# Course Documentation Directory

Welcome to the documentation suite for the **ITI Object-Oriented Programming (OOP) in C++** laboratory assignments.

## Available Documents

1. **[Comprehensive Problems Catalog (`PROBLEMS.md`)](./PROBLEMS.md)**
   - Detailed task descriptions for all 12 lab days.
   - Required vs. optional problems and bonus challenges.
   - Direct links to source code files across all labs.
   - Algorithm explanations, mathematical formulas, and technical highlights.

2. **[Setup & Compilation Guide (`SETUP_GUIDE.md`)](./SETUP_GUIDE.md)**
   - IDE configuration for Code::Blocks (`.cbp` files).
   - Command-line compilation using GCC/MinGW (`g++`).
   - Disabling Return Value Optimization (RVO) via `-fno-elide-constructors` for Day 8 tracing.
   - Setting up WinBGIm / `graphics.h` for Labs 11 and 12.
   - Console manipulation utility reference (`MyLibrary.h`).

3. **[OOP Concepts & Architectural Reference (`OOP_CONCEPTS_CHEATSHEET.md`)](./OOP_CONCEPTS_CHEATSHEET.md)**
   - Theoretical concepts covering the transition from Procedural C to dynamic OOP.
   - The Rule of Three (Destructor, Copy Constructor, Copy Assignment Operator).
   - Deep vs. Shallow copying and pointer aliasing.
   - Operator overloading signatures and patterns.
   - Inheritance access modes (`public`, `protected`, `private`).
   - Object relationships: Association, Composition, and Aggregation.
   - Dynamic Polymorphism, Virtual Functions, and VTables.
